What it does

One clear view of the room

Bask turns compatible Govee sensors into a dashboard you can read from across the room.

🟢

Clear room status

See “all good” when readings are in range, or a direct alert naming the enclosure and problem.

🦎

Per-species ranges

Set warm-side, cool-side, and humidity targets for each species. Built-in presets are editable starting points.

☀️🌙

Day and night targets

Switch target ranges automatically with your lighting schedule.

📡

Passive Bluetooth

Reads supported Govee broadcasts without pairing, a Govee account, or wires across the room.

🔋

Battery and signal

Know when a sensor battery is low or a reading has gone stale.

📲

Optional phone alerts

Send a notification when an enclosure needs attention, using the provider you choose.

📱

Home-screen app

Add Bask to a phone or tablet for a full-screen app experience. No app store required.

🔒

Local by default

Core monitoring runs on your own hardware with no Animal Room account. Optional integrations connect only when you enable them.

What you’ll need

Three things

No soldering or custom wiring.

🥧

A Raspberry Pi

Use a supported 64-bit model running Raspberry Pi OS. A Pi Zero 2 W can run Bask alone; choose at least 2 GB if you may add Shed.

🌡️

Govee H5075 sensors

One small thermo-hygrometer in each enclosure you want to watch. Affordable and widely available.

📱

Any screen

View it on your phone, a tablet, an old monitor, or a smart display — anything with a web browser on your Wi-Fi.

Getting started

Install in four steps

Start Raspberry Pi OS, run one installer command, then add your sensors.

1

Start Raspberry Pi OS

Use the working OS card that came with your Pi, or install Raspberry Pi OS (64-bit) with Raspberry Pi Imager. Connect the Pi to your home network.

2

Open Terminal

Use Terminal directly on the Pi desktop, or enable SSH and connect from another computer. No Linux or Docker knowledge is needed.

3

Paste one line

The installer prepares Docker and Bluetooth, downloads Bask, and sets it to start automatically. Nothing is compiled on the Pi.

4

Open it & add your sensors

Open the numeric address printed by the installer, such as http://192.168.1.50:8080. Tap ⚙ Manage → Pair by proximity, hold a Govee sensor near the Pi, and assign it to an enclosure.

A .local name is also provided, but it does not work on every device. Use the numeric address if it will not load.

Good to know

Questions keepers ask

Is it free?

Yes. Bask is open source under the MIT license, with no subscription or paid features. Optional tips support testing and development.

Do I need to be techy?

No. Start Raspberry Pi OS, open Terminal, and paste one line. The installer handles Docker, Bluetooth, persistent storage, and automatic startup. The beginner guide explains both the on-screen and remote-SSH routes.

Will it work for my animals?

Bask works for any keeper using Govee H5075 sensors. It ships with starting temperature and humidity ranges for several common reptiles, and you can adjust every number to match your species and your room. It’s a monitoring aid, not veterinary advice — always verify against trusted care resources.

Is my information private?

Yes. Sensor readings, enclosure settings, and history stay on your own Raspberry Pi. Core monitoring needs no account or cloud. Optional integrations such as ntfy alerts or Cielo room climate contact only the service you choose to connect.

How do updates work?

Run the same one-line installer again. It downloads the current prebuilt image and restarts Bask on it, without replacing your settings or history. Nothing is compiled on your Pi, so an update is a download rather than a long rebuild. The Settings screen also provides a portable backup download.

It installed, but the address will not load

Use the numeric address printed by the installer, such as http://192.168.1.50:8080. A .local address does not work on every device. Low memory can also stop an app from starting.

Run curl -fsSL https://animalroom.app/doctor.sh | bash for a read-only diagnostic report. It excludes records, passwords, access codes, and secret values.

Can I show it on a wall display?

Yes. Open it on a cheap wall-mounted tablet, an old phone, a monitor, or a smart display like an Amazon Echo Show — anything with a web browser on your network.
